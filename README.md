# Сапёр

## Описание проекта

«Сапёр» — игра на Python с графическим интерфейсом Tkinter, разработанная в рамках лабораторной работы.

Игроку необходимо открыть все безопасные клетки на поле 9×9, содержащем 10 мин. Числа показывают количество мин в соседних клетках. Предполагаемые мины можно отмечать флагами.

Возможности приложения:

- безопасное первое открытие;
- автоматическое раскрытие пустых областей;
- установка и снятие флагов;
- определение победы и поражения;
- автоматический перезапуск через две секунды после поражения;
- меню приложения и настройка размеров окна;
- обработка ошибок пользовательского ввода.

## Структура проекта

```text
lab3/
├── board.py          # Игровая логика
├── game.py           # Графический интерфейс
└── main.py           # Точка входа
```



## Модули

### board.py

Содержит класс `Board`, который хранит состояние поля и реализует правила игры.

Основные методы:

- `neighbors(r, c)` — получение координат соседних клеток;
- `number(r, c)` — подсчёт мин вокруг клетки;
- `toggle_flag(r, c)` — установка или снятие флага;
- `reveal(r, c)` — открытие клетки, раскрытие пустой области и проверка результата игры.

Мины, открытые клетки и флаги хранятся в множествах координат. Для раскрытия пустых областей используется стек на основе списка.

### game.py

Содержит класс `Game`, отвечающий за графический интерфейс:

- создание окна и меню;
- отображение поля на `Canvas`;
- обработку мыши и клавиатуры;
- изменение размеров окна и клеток;
- ручной и автоматический перезапуск;
- отображение сообщений об ошибках.

Модуль импортирует класс `Board` из `board.py`. В конце `game.py` находится блок запуска приложения.

## Установка и запуск


### Подготовка

Скачайте проект и откройте терминал в его папке:

```bash
cd путь/lab3
```



### Запуск

Выполните:

```bash
uv run main.py
```



## Управление

| Действие | Управление |
|---|---|
| Открыть клетку | Левая кнопка мыши |
| Поставить или снять флаг | Правая кнопка или Ctrl + левая кнопка |
| Новая игра | F2 или «Игра → Новая игра» |
| Настроить размеры окна | «Настройки → Размер окна» |
| Выйти | «Игра → Выход» |

После поражения мины отображаются на поле в течение двух секунд, затем начинается новая партия. Для победы необходимо открыть все 71 клетку без мин.
